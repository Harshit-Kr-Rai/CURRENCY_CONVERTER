# 💱 Currency Converter Web Application

🌍 A fast, responsive, and user-friendly **Currency Converter Web App** built using **HTML, CSS, and JavaScript**.  
It converts currency values in real time using live exchange rates with a clean, modern, and intuitive UI.

🔗 **Live Demo:** https://stupendous-kulfi-9885dc.netlify.app/

---

## 🚀 Project Overview

This project is a frontend web application designed to demonstrate **core web development skills** such as DOM manipulation, API integration, responsive design, and clean code structure.  
The application is lightweight, beginner-friendly, and deployed using **GitHub Pages**.

---

## ✨ Features

- Real-time currency conversion  
- Supports multiple international currencies  
- Clean and modern user interface  
- Fully responsive (mobile & desktop)  
- Dynamic currency dropdowns  
- Optimized JavaScript logic  
- Free deployment using GitHub Pages

## 🛠️ Tech Stack

## ⚙️ How It Works

1. User enters the amount  
2. Selects source and target currencies  
3. Application fetches real-time exchange rates from the API  
4. Converted amount is displayed instantly

## 🧪 How to Run Locally

1. Clone the repository:
```bash
git clone https://github.com/your-username/currency-converter.git
```

2. Navigate to the project directory:
```bash
cd currency-converter
```

3. Add your API key:
```js
// api_key.js
const exchangeApiKey = "63dca2ad503fd832a99efb80";  
const fmpApiKey = "tXVJUs6hfZO9io47YzkeVzlhOlzyCaEg";  // 👈 use this for forex quotes
```

4. Open `index.html` in your browser.

## 🌐 Deployment

This project is deployed using **GitHub Pages**.

### Deployment Steps:
1. Push the project to GitHub  
2. Go to **Repository → Settings → Pages**  
3. Select `main` branch and `/ (root)`  
4. Save and deploy  

🎉 Your website will be live within seconds.
